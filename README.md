# GitHub Achievements Lab

Repository used to test GitHub platform features such as pull requests,
issues, discussions and collaborative commits.

## Structure

```
achievement-tests/
├── quickdraw/
├── yolo/
├── pull-shark/
├── pair-extraordinaire/
└── discussions/
```

## Purpose

This repository is used to earn GitHub Profile Achievements legitimately
by performing real actions on the platform: opening/closing issues,
creating and merging pull requests, and enabling discussions.
